## Projeto em destaque

### [hub_vagas](https://github.com/Willian-Cruz/hub_vagas) — Job Market Analytics

Pipeline ETL que monitora o mercado de vagas de Dados no Brasil.

- **Coleta** em 3 portais (Vagas.com, InfoJobs e Gupy) com Playwright e BeautifulSoup
- **Normalização** de senioridade, localização e salário, e extração de 18 tecnologias citadas nas descrições
- **Modelagem** em PostgreSQL com SQLAlchemy (`jobs` ↔ `technologies`, relação muitos-para-muitos)
- **Orquestração** diária com APScheduler, métricas de execução e logs com rotação
- **Análise** via exportação para Excel e dashboard no Power BI
- **Qualidade:** 133 testes com pytest e CI no GitHub Actions

`Python` `Playwright` `PostgreSQL` `SQLAlchemy` `Pydantic` `Pandas` `Power BI` `GitHub Actions`
